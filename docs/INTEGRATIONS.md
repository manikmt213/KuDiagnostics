# KuDiagnostics — integrations

Generated by `node scripts/tool-reference.mjs` from the integration catalogue (`src/Modules/Core/IntegrationCatalog.php`). Do not edit by hand.

86 products: 37 full, 38 partial, 10 detection only, 1 none. **Full** means real operations tested against the real product; **partial** means some operations, or tested against a stand-in built from the product's source; **detection** means KuDiagnostics recognises it but has no tools for it. On a site, Claude sees only the tools of products that are active (ask it to run `kuduy-integrations`); site administrators see the same list under Tools > KuDiagnostics > Integrations.
